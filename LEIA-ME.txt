-------------------------------------------------------------------------------
  COMO EXECUTAR O PROGRAMA
-------------------------------------------------------------------------------

  Requisito: Python 3.11 ou superior. Nenhuma biblioteca externa.

      python gestao_sessoes.py

  O programa abre um menu com 7 opcoes. Ele ja inicia com 180 sessoes de
  recarga carregadas de chargegrid.db, entao listar, buscar, ordenar e as
  estatisticas tem dados de verdade desde o primeiro segundo.

  Para conferir os algoritmos sem abrir o menu:

      python gestao_sessoes.py --autoteste

  A opcao 6 do menu ("Comparar algoritmos") mede quantas comparacoes cada
  algoritmo faz em entradas de tamanho crescente. E de la que saem todos os
  numeros da analise de complexidade do relatorio - nenhum foi estimado.


-------------------------------------------------------------------------------
  ARQUIVOS NESTA PASTA
-------------------------------------------------------------------------------

  gestao_sessoes.py            O programa da Sprint. 830 linhas, so
                               biblioteca padrao. Contem os quatro

-------------------------------------------------------------------------------
  SOBRE A PASTA aplicativo-web/
-------------------------------------------------------------------------------

  O ChargeGrid Intelligence e um projeto unico atendendo varias disciplinas da
  Sprint. A pasta aplicativo-web/ tem o sistema completo: aplicacao Flask com
  mapa de eletropostos, controle dinamico de potencia entre conectores,
  tarifacao em tres eixos, carteira com cashback, reserva de conector com
  sinal, pagamento e simulacao do protocolo Modbus TCP.

  Ele NAO faz parte da avaliacao desta disciplina, e usa sorted() livremente -
  o que o enunciado permite "nas demais partes do sistema". Todos os
  algoritmos avaliados aqui estao em gestao_sessoes.py, escritos a mao.

  Esta na entrega por dois motivos: e de onde vem o chargegrid.db com o
  historico real, e mostra de onde os dados que o programa organiza saem.

  Para rodar o aplicativo web, se houver interesse:

      cd aplicativo-web
      pip install flask pytest
      python app.py
      # abre em http://localhost:5001

  No Windows, dois cliques em aplicativo-web\iniciar.bat abrem um menu com o
  aplicativo, o programa desta Sprint e a suite de testes.

  Contas de demonstracao (senha 1234 para todas): amanda, allan, jose, mylon.

  A suite de testes do projeto tem 142 testes, dos quais 16 cobrem os
  algoritmos desta Sprint (classe TestGestaoSessoes):

      cd aplicativo-web
      pytest test_chargegrid.py

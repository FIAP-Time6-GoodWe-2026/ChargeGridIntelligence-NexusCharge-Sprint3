-------------------------------------------------------------------------------
  COMO EXECUTAR O PROGRAMA
-------------------------------------------------------------------------------

  Requisito: Python 3.11 ou superior. Nenhuma biblioteca externa.

      cd estruturas-de-dados
      python gestao_sessoes.py

  O programa abre um menu com 7 opcoes. Ele ja inicia com 180 sessoes de
  recarga carregadas do banco do aplicativo web, entao listar, buscar, ordenar
  e as estatisticas tem dados de verdade desde o primeiro segundo.

  Para conferir os algoritmos sem abrir o menu:

      python gestao_sessoes.py --autoteste

  A opcao 6 do menu ("Comparar algoritmos") mede quantas comparacoes cada
  algoritmo faz em entradas de tamanho crescente. E de la que saem todos os
  numeros da analise de complexidade do relatorio - nenhum foi estimado.

  No Windows, dois cliques em iniciar.bat abrem um menu com o aplicativo web,
  este programa e a suite de testes.


-------------------------------------------------------------------------------
  ESTRUTURA DO PACOTE
-------------------------------------------------------------------------------

  Duas pastas, uma por natureza de entrega.

  estruturas-de-dados/         A ENTREGA DESTA DISCIPLINA

    gestao_sessoes.py          O programa da Sprint. 836 linhas, so
                               biblioteca padrao. Contem os quatro
                               algoritmos escritos a mao:
                                 - busca sequencial      O(n)
                                 - busca binaria         O(log n)
                                 - bubble sort           O(n2)
                                 - insertion sort        O(n2) / O(n)

    RELATORIO_SPRINT3_DSA.pdf  O relatorio. 12 paginas.
    RELATORIO_SPRINT3_DSA.md   O mesmo relatorio em texto.

  aplicativo-web/              O SISTEMA (outras disciplinas da Sprint)

    Aplicacao Flask com mapa de eletropostos, controle dinamico de potencia
    entre conectores, tarifacao em tres eixos, carteira com cashback, reserva
    de conector com sinal, pagamento e simulacao do protocolo Modbus TCP.

    chargegrid.db              Historico de 180 sessoes. E daqui que o
                               programa da Sprint le os dados. Sem este
                               arquivo ele abre com a lista vazia, e o
                               cadastro pelo menu preenche.

  iniciar.bat                  Menu de inicializacao para Windows.
  README.md                    Documentacao geral do projeto.


-------------------------------------------------------------------------------
  SOBRE A PASTA aplicativo-web/
-------------------------------------------------------------------------------

  O ChargeGrid Intelligence e um projeto unico atendendo varias disciplinas da
  Sprint. O aplicativo NAO faz parte da avaliacao desta disciplina, e usa
  sorted() livremente - o que o enunciado permite "nas demais partes do
  sistema". Todos os algoritmos avaliados aqui estao em gestao_sessoes.py,
  escritos a mao.

  Esta na entrega por dois motivos: e de onde vem o historico real que o
  programa organiza, e mostra de onde esses dados saem.

  Para rodar, se houver interesse:

      cd aplicativo-web
      pip install flask pytest
      python app.py
      # abre em http://localhost:5001

  Contas de demonstracao (senha 1234 para todas): amanda, allan, jose, mylon.

  A suite tem 146 testes, dos quais 16 cobrem os algoritmos desta Sprint
  (classe TestGestaoSessoes) e 4 cobrem a tabela ordenavel do relatorio:

      cd aplicativo-web
      pytest test_chargegrid.py
